# bearing-helix-research

A research crate (not a product) for one question: **if a rotating machine's
vibration is stored in a format folded at its own shaft period, is the
format's byte rate itself an early failure alarm?**

The format (the *fold*): revolutions segmented at fractional sample
boundaries from vibration-refined speed (no tachometer) → a closed-loop
time-synchronous-average **pool** predicts every sample (decoder mirrors it;
nothing extra on the wire) → the residual is Rice-coded, bit-exact at q=1 or
under a hard ±0.10 % FS bound for wireless. A healthy machine codes at the
sensor-noise entropy floor, flat; a growing defect writes unpoolable impulses
and the bytes/rev climbs. **The stream's own accounting is the monitor.**

The helix state (A, I) per revolution rides on top through the locked beehive
formulas (F, h, κ, τ), ported from the audio engine and pinned to it by
fixture parity — machines are the framework's third ω/n domain after bars
(music) and optical pulses (zinc). See `theory/00-rotation-spine.md`.

## The numbers (SYNTHETIC rig, seeds fixed — real-data runs still open)

Shared alarm rule for every indicator: reference = first 25 % of life (≤5 h),
alarm at μ+5σ for 3 consecutive snapshots. Ground-truth failure from the rig.

| lead time before failure | A: ZA-2115 outer | B: SKF-6205 inner |
|---|---|---|
| **fold bytes/sample (steady-state)** | **8.26 h** | **5.95 h** |
| envelope line — *told the fault order* | 8.10 h | 5.79 h |
| kurtosis | 4.26 h | 2.95 h |
| crest factor | 4.26 h | 3.45 h |
| RMS | 3.26 h | 2.12 h |
| healthy 30 h control | 0 false alarms | (all indicators) |

Bytes on the healthy stretch (profile A): raw 16.00 → zstd-19 12.91 → fold
lossless **10.29** bits/sample (1.56× vs raw; ~2 % above the rig's Gaussian
noise-entropy floor of 10.08) → fold bounded ±0.10 % FS **4.27** bits/sample
(3.74× vs raw, 3.0× vs zstd; measured worst error 0.0977 % FS).

Helix odometer: climb/rev bends **1.15×** (A) / **1.08×** (B) after onset —
an odometer, not an alarm; the climb-rate alarm loses to the byte-rate level.

## The event layer

When the byte rate leaves noise, `event.rs` files a **defect event** — a
sensory-metadata object anchored to the helix by its revolution index
(`bench_out/events.json`): detection stamped at one-rev precision by a
per-rev CUSUM plus a noise-floor-departure back-estimate; the component named
by fault-order envelope scoring (outer/inner correct at 18–24× margin on the
rig); the inner-race angle recovered from the load-zone phase fold (3–6°
error at 0.7 confidence); and a wait-until-distinguishable disposition —
still-growing departures become a **maintenance request** (growth rate +
service-by extrapolation), stationary low departures are **absorbed**: the
reference re-bases, monitoring re-arms, and the event stays on the record as
the machine's new voice. Ground truth sits beside every claim in the bench
printout.

## Honesty ledger

| Claim | Status |
|---|---|
| Fractional-period fold: bit-exact lossless roundtrip, decoder-mirrored pool | ✅ **holds** (tests) |
| Bounded mode: worst error ≤ 0.10 % FS at 3.74× vs raw | ✅ **holds** (tests + bench, synthetic) |
| Speed from vibration alone, <2·10⁻⁴ relative, with drift + load wobble | ✅ **holds** (test-enforced) |
| Byte rate alarms before RMS/kurtosis/crest, matches the informed envelope line | 🟡 **holds on the synthetic rig only** — real-data runs not yet done |
| Lossless sits on the sensor-noise entropy floor | ✅ **holds** on the rig (within ~2 % of the Gaussian floor) |
| "Lossless beats zstd by 20 %" | 🟡 rig-dependent; unverified on real sensors |
| Helix climb = wear odometer | 🟡 **holds, weakly** (1.08–1.15× bend) |
| Climb *rate* as the alarm | 🔴 **breaks** — departure level wins |
| Geometry port ≡ Python engine | ✅ **holds** (fixture parity ≤1e-9) |
| Component ID from the fault order (outer/inner) | ✅ **holds on the rig** (18–24× margin; real data open) |
| Inner-race angle from the load-zone phase fold | ✅ **holds on the rig** (3–6° error); outer needs a 2nd channel — stated, not guessed |
| Onset back-estimate (noise-floor departure) | 🟡 ±2 h fuzz, worst on slow plateaus; the seeding moment is unidentifiable in principle |
| Service-by extrapolation on the byte rate | 🔴 **leans late** (log meter compresses at high severity; A: 26.1 h vs true 22.8) — hand off to an energy-scale indicator late-stage |
| "No shipped format does this" | 🟡 **grounded-conjecture**, scoped in `briefing/PRIOR_ART.md` |
| First rig's √wear noise floor | 🔴 **broke honestly** — stepped at onset, gifted the format an instant alarm; fixed to linear (theory/00) |
